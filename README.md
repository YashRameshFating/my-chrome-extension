# Email Writer Generator

AI-powered Gmail extension that generates email replies in **Formal**, **Informal**, and **Friendly** tones with a single click.

## Features

* Generate AI-powered email replies directly inside Gmail.
* Choose between Formal, Informal, and Friendly tones.
* Fast and easy one-click response generation.
* Saves time when replying to emails.

## Installation Guide

### Step 1: Download the Extension

1. Open this repository.
2. Click **Code** → **Download ZIP**.
3. Extract the ZIP file to a folder on your computer.

### Step 2: Load the Extension in Chrome

1. Open Google Chrome.
2. Navigate to:

   ```
   chrome://extensions/
   ```
3. Enable **Developer Mode** (top-right corner).
4. Click **Load unpacked**.
5. Select the extracted extension folder.

The extension is now installed.

## How to Use

### Step 1: Open Gmail

Go to:
https://mail.google.com

### Step 2: Open an Email

Open any email you want to reply to and click **Reply**.

### Step 3: Generate a Reply

1. Click the **AI Reply** button.
2. Select a tone:

   * Formal
   * Informal
   * Friendly
3. Wait a few seconds while the AI generates a response.
4. Review the generated reply.
5. Edit if needed and click **Send**.
